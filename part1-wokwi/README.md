\# Part 1 - Smart Gate Simulation



\## Objective

The objective of this task was to simulate a smart gate system capable of detecting vehicles and controlling gate movement automatically.



\## Components Used

\- Arduino Uno

\- HC-SR04 Ultrasonic Sensor

\- Servo Motor

\- LED Indicator



\## Features

\- Vehicle detection using ultrasonic sensor

\- Automatic gate opening

\- LED blinking during gate movement

\- Automatic gate closing after 5 seconds

\- Safety check before closing the gate



\## Platform

Wokwi Simulator



\## Output

The simulation demonstrates automated gate control logic using embedded programming and hardware interfacing.

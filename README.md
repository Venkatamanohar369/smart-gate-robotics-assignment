# Smart Gate Robotics Assignment

This repository contains my submission for the Robotics Assignment provided by APTCODER.

The project is divided into three parts:

## Part 1 - Hardware Logic and Simulation
A smart gate automation system was developed using Arduino and Wokwi simulation.
The system detects vehicles using an ultrasonic sensor and controls a servo motor gate.
An LED indicator blinks while the gate is moving.

## Part 2 - Blockly Integration
A custom Blockly block named `open_gate_with_speed` was created using JavaScript.
The block accepts a speed input from 1 to 10 and generates servo motor control code.

## Part 3 - Frontend Dashboard
A frontend dashboard was developed using HTML, CSS, and JavaScript.
The dashboard simulates a live smart gate monitoring interface with dynamic gate status updates.

## Technologies Used
- Arduino Uno
- Wokwi Simulator
- Blockly
- HTML
- CSS
- JavaScript
- Tailwind CSS
